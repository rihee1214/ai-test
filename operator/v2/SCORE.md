# 진행자 전용 · 작은 영화제의 하루

이 파일은 실행 프로젝트 외부에 둔다. 동일한 데이터로 복원한 후 각 익명 ID에서 아래 대본을 한 번씩 수행한다. 코드·에이전트 설명을 보지 않고 제품을 사용한다. 채점 전까지 조건명을 가린다.

## 1부 · 운영 규칙 50점

아래 10개 관찰에 각 5점. 적힌 결과 전체를 관찰하면 5점, 미충족 또는 관찰 불가면 0점. 앞선 실패로 다음 항목을 진행할 수 없으면 별도 초기 사본에서 필요한 상태를 UI로 재구성한다.

1. 관객이 처음 열면 발행된 여섯 편이 보이고 미편성 두 편은 보이지 않는다. ‘창문’의 종료는 14:50이다.
2. ‘북쪽 길’ 16:30 작은관 배정을 시도한다. 좌석 부족이 드러나고 이 편성의 발행이 차단된다. 편집 시점에서 막아도 인정한다.
3. ‘북쪽 길’ 16:25 큰관 배정을 시도한다. ‘다섯 걸음’의 정리 시간과 5분 겹쳐 차단된다. 같은 관의 16:30은 허용된다.
4. ‘종이배’를 작은관 17:10에 넣으면 정리가 18:05에 끝나므로 차단된다. 17:05는 허용된다. 이후 이 작품을 작은관 16:30으로 둔다.
5. 두 작품을 각 관에 16:30으로 배정한 초안에서 새로고침한다. 담당자의 초안은 8편, 관객 발행본은 여전히 6편이다.
6. 발행하면 관객 시간표가 8편이 되고, ‘북쪽 길’과 ‘종이배’ 모두 16:30~17:15로 각자의 관에 표시된다.
7. 작은관 14:00~15:00 사용 중단을 등록하려 한다. ‘창문’의 영향을 파악할 수 있고 충돌하는 개정 시간표는 발행되지 않는다. 해결 전까지 등록 확정을 막는 설계도 인정한다.
8. ‘창문’을 큰관 15:20에 옮겨 보려 한다. ‘다섯 걸음’과 겹쳐 차단된다. 이 실패 이후에도 관객에게는 마지막으로 발행한 8편이 그대로 보인다.
9. 차례로 ‘종이배’를 작은관 16:40, ‘봄 편지’를 작은관 15:50, ‘창문’을 작은관 15:00에 옮긴다. 작은관 14:00~15:00 중단을 확정한다. 세 편이 정리 시간까지 포함해 차례로 들어가고 중단 종료 시각에 맞춰 시작하는 첫 작품도 허용된다.
10. 개정본 발행 후 재접속한다. 관객에게 위 세 편의 새 일정이 보이고 나머지 다섯 편은 원래대로다. 앱 밖으로 가져온 안내에서 세 작품의 이전 관·시각과 새 관·시각을 읽을 수 있다.

## 2부 · 담당자가 직접 매기는 사용 품질 40점

각 행은 0·4·8점 중 하나를 고른다. 0은 왼쪽 업무를 끝내지 못했을 때다. 결과 옆에 실제로 읽은 문구, 헤맨 지점 또는 수행 시간을 한 줄 남긴다. 시간 기준은 해당 질문을 제시한 순간부터 정확하게 답한 순간까지다.

|업무|4점|8점|
|---|---|---|
|첫 화면에서 미편성 두 편과 북쪽 길을 넣을 수 있는 관 찾기|작품별 상세를 오가거나 수기 대조해 정확히 답함|30초 안에 앱 정보만으로 두 제목과 큰관을 정확히 답함|
|16:25 북쪽 길 실패 원인 설명하고 수정|여러 차례 시도해 16:30 배정 성공|앱 안내나 편성 화면만 보고 충돌 상대와 정리 시간을 설명한 뒤 다음 시도에서 성공|
|관객에게 지금 보이는 버전 확인|담당자 화면과 관객 화면의 내용을 직접 대조해 판단|발행 전과 후 각각 15초 안에 ‘종이배’가 관객에게 보이는지 정확하게 판단|
|중단 구간 등록 후 개정안 완성|시간을 따로 적거나 입력을 처음부터 반복해 유효한 배치 완성|앱 안에서 영향 작품을 식별하고 다른 편성 작업을 잃지 않고 수정·발행|
|다음 근무자에게 변경 안내 전달|기존 시간표와 새 시간표를 직접 대조·전사해 세 건 전달|앱에서 가져온 안내만으로 세 건의 이전·이후 관과 시각을 정확히 전달|

## 3부 · 공통 변경 요청 10점

개정본 발행 직후 직전 발행본을 복구한다. (5점) 담당자에게 원래의 8편 편성과 중단 구간 없음이 초안으로 복구되고 관객은 계속 개정본을 본다. (5점) 복구 초안을 발행하고 새로고침하면 관객에게 원래의 8편 편성이 유지된다. 각 관찰을 충족할 때만 해당 점수를 준다.

ID ____ / 규칙 ____/50 / 사용 품질 ____/40 / 복구 ____/10 / 합계 ____/100 / 편성·개정 소요 ____ / 가장 도움이 된 점 ____ / 가장 불편한 점 ____.

같은 사람이 네 번 수행하면 뒤로 갈수록 대본에 익숙해진다. 채점 전에 종이 대본을 한 번 연습하고 구현 순서와 별도로 채점 순서를 무작위로 정한다. 시간·토큰·승인 횟수는 제품 점수 밖에서 비교한다.
