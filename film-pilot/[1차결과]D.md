‘작은 영화제의 하루’를 구현했습니다. 담당자는 두 상영관의 초안을 편집하고, 관객은 마지막으로 발행한 시간표를 봅니다. 외부 패키지 설치나 계정 없이 실행됩니다.

실행 방법
프로젝트 루트에서 node server.mjs를 실행하고 Edge에서 작은 영화제의 하루를 여세요. 초기 상태로 되돌리려면 편성 데스크 → 초기 데이터 복원을 선택하고 확인하세요.

직접 검증한 결과

| 검증 항목 | 확인한 결과 |
|---|---|
| 편성 규칙 | Node 24 테스트 3개가 통과했습니다. 좌석 초과와 정리 시간 충돌을 검출했고, 정리가 18:00에 끝나면 허용하고 18:01이면 발행을 차단했습니다. |
| 초안과 관객 시간표 | 별도 Edge 관객 탭을 열고 ‘종이배’를 작은관 16:20에 추가했습니다. 관객 탭은 발행 전까지 6편을 유지했고, 발행 후 새로고침 없이 7편과 상영 종료 시각 17:05를 표시했습니다. |
| 중단과 재편성 | 작은관에 17:05~17:15 중단을 등록하자 ‘종이배’의 정리 시간과 겹쳐 발행이 차단됐습니다. 오류를 눌러 큰관 16:30으로 옮긴 뒤 재발행했습니다. 중단 구간 수정과 삭제도 확인했습니다. |
| 스태프 안내 | 실제로 내려받은 텍스트 파일에서 ‘종이배’의 이전 일정 작은관 16:20~17:05와 새 일정 큰관 16:30~17:15를 확인했습니다. |
| 재시작과 초기화 | Edge를 종료하고 같은 프로필로 다시 열었을 때 미발행 초안, 관객 발행본, 중단 구간, 직전 변경 안내가 복원됐습니다. 초기화 후에는 최초 편성 6편과 미편성 2편으로 돌아갔습니다. |

검증 범위
Windows의 Edge 157을 헤드리스 모드로 실행해 1280×800에서 검증했고, 초기 화면 캡처도 확인했습니다. 실제 Edge 창에서 마우스와 키보드만으로 전체 흐름을 수동 조작하는 검증은 수행하지 않았습니다.
