# 작은 영화제의 하루

당신은 독립영화제의 편성 담당자다. 두 상영관의 하루 일정을 짜고, 변경이 생겨도 관객과 현장 스태프가 각각 믿고 쓸 시간표를 만드는 로컬 웹 앱을 만들어 주세요.

## 사용자가 끝내야 할 일

1. 기존 편성에 미편성 작품을 추가하고 시간이나 상영관을 바꾼다. 운영 불가능한 편성이 있으면 문제를 찾아 고칠 수 있다.
2. 초안을 작업하는 동안 관객은 마지막으로 발행한 시간표를 본다. 담당자가 발행하면 새 시간표가 관객에게 반영된다.
3. 발행 뒤 상영관 사용 중단 구간을 등록하고 다시 편성한다. 담당자는 이전 발행본에서 무엇이 바뀌었는지 확인하고, 스태프에게 전달할 변경 안내를 앱 밖으로 가져갈 수 있다.
4. 브라우저를 다시 열어도 초안과 발행본으로 업무를 이어간다.

## 운영 사실

- 한 날, 13:00~18:00 운영. 상영관은 큰관 80석, 작은관 40석이다.
- 관람 예상 인원은 상영관 좌석 수 이하여야 한다. 각 작품은 한 차례만 상영한다.
- 상영 시간은 영화와 관객 대화(GV)를 합한 시간이다. 그 뒤 같은 관에서 10분 동안 정리한다. 정리까지 운영 시간 안에 끝나야 한다. 사용 중단 구간에는 상영과 정리 모두 들어갈 수 없다. 앞 구간이 끝나는 시각에 다음 구간을 시작할 수 있다.
- 미편성 작품이 일부 있어도 현재 편성된 작품의 일정은 발행할 수 있다. 규칙을 위반한 일정은 발행할 수 없다.
- 관객에게 필요한 정보는 작품, 관, 시작·종료 시각이다. 스태프는 변경된 작품의 이전 일정과 새 일정을 알아야 한다.

## 제공 방식

한국어 데스크톱용 로컬 웹 앱. Windows, Node 24, Edge, 1280×800 콘텐츠 뷰포트. 외부 서비스와 계정 없이 실행한다. 실행 명령 하나와 초기 데이터를 복원하는 방법을 제공한다. 관객과 담당자는 같은 브라우저에서 역할별로 확인할 수 있으면 된다. 실제 인증, 티켓 판매, 서버 배포는 범위 밖이다.

달력, 목록, 보드, 편집 흐름, 안내 형식은 팀이 결정한다. 사용자가 상영 가능 여부를 판단하고 변경된 일정을 다른 사람에게 정확히 전달할 수 있는지가 중요하다.
