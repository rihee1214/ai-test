# 작은 영화제의 하루

Windows에서 Node.js 24로 실행하는 독립영화제 하루 편성 앱입니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
node server.js
```

Edge에서 [편성실](http://127.0.0.1:4317/#planner)을 엽니다. 같은 프로필의 별도 탭에 [관객 시간표](http://127.0.0.1:4317/#audience)를 열면 발행 결과를 함께 확인할 수 있습니다. 서버는 이 컴퓨터의 루프백 주소에서 실행되며 터미널에서 Ctrl+C로 종료할 수 있습니다.

## 편성과 발행

1. 타임라인의 작품이나 미편성 작품을 선택합니다. 상영관과 시작 시각을 정하고 **초안에 저장**을 누릅니다. 사선으로 표시된 작품 끝부분은 같은 관을 사용하는 정리 10분입니다.
2. **편성 점검**의 문제에서 작품 편집으로 이동해 수정합니다. **사용 중단 관리**에서 관별 중단 구간을 등록하거나 해제할 수 있습니다.
3. **발행 검토**에서 이전 일정과 새 일정을 확인하고 **관객 시간표 발행**을 누릅니다. 관객 화면은 발행할 때 갱신됩니다.
4. **발행 변경 안내**에서 최근 두 발행본의 차이를 확인하고, 스태프에게 전달할 한글 텍스트 파일을 내려받습니다.

## 저장과 복원

잘못 발행했을 때는 **직전 발행본 복구 → 초안으로 복구**를 선택합니다. 현재 초안의 작품 배정과 사용 중단 구간이 직전 발행 당시의 내용으로 교체됩니다. 확인한 뒤 **발행 검토 → 관객 시간표 발행**을 눌러 관객에게 반영합니다. 사용 중단 구간만 바뀐 경우에도 발행할 수 있습니다.

업데이트 전 저장본도 같은 주소와 프로필에서 이어서 사용할 수 있습니다. 이전 버전이 기록하지 않은 과거 발행 시점의 중단 구간은 복구할 수 없습니다. 최초 발행본의 중단 구간은 비어 있고, 업데이트 후 발행한 일정부터 중단 이력이 함께 보존됩니다.

초안, 사용 중단 구간, 최근 발행본과 그 직전 발행본은 Edge의 로컬 저장소에 보관됩니다. 다시 작업할 때는 같은 브라우저 프로필과 위 주소를 사용합니다.

편성실 하단의 **초기 데이터 복원**을 누른 뒤 **초기 상태로 복원**을 선택하면 최초 발행된 여섯 편, 미편성 두 편, 사용 중단 구간이 없는 상태로 돌아갑니다.

## 규칙 테스트

```powershell
node --test test/schedule.test.mjs
```

서버를 실행한 상태에서 두 번째 터미널의 프로젝트 폴더에서 `node checks/edge.mjs`를 실행하면 Windows Edge의 새 임시 프로필로 편집, 발행, 다운로드, 브라우저 재시작과 복원을 검증합니다.
