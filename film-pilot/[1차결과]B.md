node server.js

초기 상태로 돌아가려면 편성실 하단의 초기 데이터 복원 → 초기 상태로 복원을 선택하세요.

### 직접 검증한 결과

Node 24에서 규칙 테스트 8개가 모두 통과했습니다. Windows Edge의 1280×800 화면에서도 다음 동작을 확인했습니다.

| 항목 | 확인한 결과 |
|---|---|
| 초안과 발행 | ‘종이배’를 추가해도 관객 탭에는 기존 6편이 유지됐습니다. ‘북쪽 길’을 미편성으로 둔 채 발행하자 관객 탭이 7편으로 갱신됐습니다. |
| 발행 차단 | 40석인 작은관에 예상 관객 60명을 배정한 경우, 같은 관의 정리 시간이 1분 겹친 경우, 사용 중단 구간이 정리와 겹친 경우 모두 발행이 차단됐습니다. |
| 운영 종료 경계 | 계획의 ‘종이배’ 17:10 시작은 정리가 18:05에 끝나 차단됐습니다. 17:05로 앞당기자 정확히 18:00에 정리가 끝나 발행됐습니다. |
| 스태프 변경 안내 | 실제 내려받은 한글 .txt에서 ‘종이배’의 이전 일정 작은관 16:20–17:05와 새 일정 큰관 17:05–17:50을 확인했습니다. |
| 재시작과 복원 | Edge를 정상 종료한 뒤 같은 프로필로 다시 열어 초안, 발행본, 사용 중단 구간, 직전 변경 안내가 유지되는지 확인했습니다. 초기 복원 후에는 발행 6편·미편성 2편으로 돌아갔습니다. |

미확인 항목은 일반 Edge 창의 다운로드 확인 대화상자와 브라우저 강제 종료 직후의 복구입니다. 브라우저 검증은 헤드리스 Edge에서 수행했습니다.
