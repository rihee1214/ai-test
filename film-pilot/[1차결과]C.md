‘작은 영화제의 하루’를 구현했습니다. 편성 데스크에서 큰관과 작은관의 일정을 나란히 보고, 작품을 눌러 상영관과 시작 시각을 바꿀 수 있습니다. 초안은 자동 저장되며 관객 시간표에는 마지막 발행본이 표시됩니다.

실행 방법
프로젝트 루트에서 node server.mjs를 실행한 뒤 Edge에서 로컬 앱 열기를 선택하세요. 별도 패키지 설치는 필요 없습니다. 최초 편성으로 돌아가려면 편성 데스크 하단의 초기 데이터 복원을 누르고 확인하세요.

직접 검증한 동작과 결과

- Edge의 1280×800 화면에서 초기 편성 6편을 확인했습니다. 미편성 작품 ‘종이배’를 작은관 16:30에 추가했을 때 관객 시간표는 기존 6편을 유지했고, 발행 후 7편으로 갱신됐습니다.
- 작은관에 16:30~16:40 사용 중단 구간을 등록하자 충돌이 표시되고 발행이 차단됐습니다. ‘종이배’를 중단 종료 시각인 16:40으로 옮기자 발행할 수 있었습니다.
- 재발행 전 Edge를 종료하고 같은 프로필로 다시 열었습니다. 초안에는 16:40, 관객 시간표에는 16:30이 유지됐습니다.
- 재발행 후 내려받은 스태프 안내문에서 종이배 | 작은관 16:30–17:15 → 작은관 16:40–17:25를 확인했습니다. 초기 데이터 복원 후에는 다시 6편이 표시됐습니다.
- Node 24에서 node --test model.test.mjs 테스트 2개가 통과했습니다. 좌석 초과, GV와 정리 시간을 포함한 충돌, 운영 종료 초과, 발행본 독립성, 작품 추가·변경·해제 기록을 검사했습니다.

확인하지 못한 항목
Edge 검증은 헤드리스 모드에서 수행했습니다. 실제 모니터에서의 시각적 가독성과 키보드만으로 전체 업무를 수행하는 흐름은 확인하지 않았습니다.
