‘작은 영화제의 하루’를 구현했습니다. 편성 보드에서 작품을 추가하거나 상영관과 시작 시각을 바꿀 수 있습니다. 관객 시간표에는 마지막 발행본이 표시되고, 변경 안내에서는 직전 발행본과 달라진 일정을 복사하거나 텍스트 파일로 저장할 수 있습니다.

실행 방법
프로젝트 루트에서 node server.cjs를 실행한 뒤 Edge에서 로컬 앱 열기로 접속하세요. 별도 패키지 설치는 필요 없습니다. 처음 상태로 돌아가려면 화면 하단의 초기 데이터 복원을 누르고 확인하세요.

직접 검증한 결과
Windows의 헤드리스 Edge에서 1280×800 콘텐츠 뷰포트로 확인했습니다.

- 초기 화면에 편성 6편과 미편성 2편이 표시됐습니다. 초안에 한 편을 추가해도 관객 화면은 6편을 유지했고, 발행 후 7편으로 바뀌었습니다.
- 좌석 초과, 정리 시간 중복, 운영 종료 시각 초과, 사용 중단 구간과 정리 시간의 충돌을 감지했습니다. 큰관의 정리가 끝나는 1630에는 다음 상영을 시작할 수 있었고, 1629에는 발행이 차단됐습니다.
- 재발행 후 내려받은 텍스트 파일에서 북쪽 길　큰관 1630–1715 → 미편성을 확인했습니다.
- Edge를 종료하고 같은 프로필로 다시 열어 서로 다른 초안과 발행본, 사용 중단 구간이 복원되는 것을 확인했습니다. 초기 데이터 복원 후에는 첫 발행본 6편으로 돌아갔습니다.

확인하지 못한 항목
실행 환경은 Node 20.12.1이어서 지정된 Node 24에서의 실행은 검증하지 못했습니다. 클립보드 복사와 여러 탭 사이의 실시간 갱신도 직접 검증하지 않았습니다.
