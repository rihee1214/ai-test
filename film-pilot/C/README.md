# 작은 영화제의 하루

프로젝트 폴더에서 `node server.mjs`를 실행하고 Edge에서 http://127.0.0.1:43871 을 엽니다. Node 24 기본 모듈만 사용합니다.

작품 카드를 눌러 상영관과 시작 시각을 편집합니다. 초안은 브라우저에 자동 저장됩니다. 발행 버튼에서 변경 내용을 확인하고 발행하면 관객 시간표가 갱신됩니다. 변경 안내에서 직전 발행의 작품별 변경을 텍스트 파일로 저장할 수 있습니다.

잘못 발행했다면 편성 데스크의 ‘직전 발행본 복구’에서 버전을 확인한 뒤 ‘초안으로 불러오기’를 누릅니다. 당시의 작품 배정과 상영관 사용 중단 구간이 현재 초안을 대체합니다. 편성을 확인하고 ‘시간표 발행’을 마치면 관객 시간표가 갱신됩니다. 사용 중단 구간만 변경한 경우에도 발행할 수 있습니다.

업데이트 전 저장한 초안과 발행본은 계속 사용할 수 있습니다. 이전 형식에서 두 번째 이후의 발행본은 발행 당시의 중단 구간을 기록하지 않았습니다. 이 경우 새 형식으로 두 번 발행하면 그중 직전 발행본부터 복구할 수 있습니다.

편성 데스크 하단의 ‘초기 데이터 복원’을 누르고 확인하면 최초 편성으로 돌아갑니다. 동일한 주소와 브라우저 프로필을 사용해야 저장된 일정을 이어 볼 수 있습니다.

규칙 검증 명령은 `node --test model.test.mjs`입니다.
