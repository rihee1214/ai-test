# 교육 키트 배정 데스크

교육센터 물품 담당자 한 명이 오전 한 차수에 한 종류의 키트를 수업별로 배정하는 한국어 데스크톱 웹 앱이다. 담당자는 어느 수업에 몇 개를 보낼지 확정하고, 다시 접속한 뒤 전달 목록을 보고 포장한다. 이번 차수는 키트 4개와 수업 3개다.

## 사용자가 할 일

- 차수를 열면 제목, 차수, 남은 키트 수, 원본 순서의 신청 세 건, 전달 목록이 한 화면에 보인다. 각 행에는 번호, 수업명, 신청 수량, 상태, 조작이 있다.
- 대기 행의 ‘배정’을 누른다. 전량을 줄 수 있으면 남은 수량에서 차감하고 상태를 ‘배정 완료’, 조작을 ‘취소’로 바꾼다. 잔량이 정확히 0이 되는 배정도 가능하다.
- 잔량이 부족해도 ‘배정’을 눌러 이유를 확인할 수 있다. ‘재고 부족’과 부족한 개수를 표시한다. 부분 배정 없이 잔량, 세 행의 상태, 전달 목록을 클릭 직전 값으로 유지한다.
- ‘취소’를 누르면 그 수업의 전량을 되돌리고 상태는 ‘대기’, 조작은 ‘배정’으로 돌린다. 다시 배정할 수 있다. 성공한 배정이나 취소는 이전 부족 안내를 지운다.
- 전달 목록에는 배정 완료 수업만 원본 순서로 한 번씩 ‘수업명 수량개’ 형태로 표시한다. 비어 있으면 ‘배정된 수업 없음’을 표시한다.
- 같은 브라우저·주소에서 새로고침하거나 탭을 닫고 다시 열어도 업무 상태를 유지한다. ‘초기화’를 한 번 누르면 원본 상태로 즉시 복원하고 부족 안내도 지운다. 새로고침 후에도 초기 상태다.

## 범위와 실행

Windows, Node 24, HTML, CSS, 브라우저 JavaScript를 사용한다. 외부 패키지, CDN, 외부 폰트 없이 저장소 루트에서 `node serve.mjs`를 실행하고 `http://127.0.0.1:4173/`을 연다. 제품 파일은 public/ 아래에 둔다. 공통 서버와 원본 데이터, 목업은 제공 자료다. seed.json을 실제 초기 데이터 원본으로 사용한다.

기준은 Edge, 확대율 100%, 콘텐츠 뷰포트 960 × 640 CSS px다. 빈 프로필이나 사이트 데이터 삭제로 첫 방문을 재현할 수 있어야 한다. 계정, 다중 사용자 동기화, 백엔드 DB, 신청 편집, 날짜 전환, 인쇄, 모바일 화면은 범위 밖이다.

## 완료 확인

- 육안으로 첫 화면은 refs/initial.svg, 대표 배정 후 화면은 refs/allocated.svg와 대조한다.
- SCENARIOS.md에서 실제 배정, 부족 처리, 취소·재배정, 재접속, 초기화의 화면과 데이터를 확인한다.
- 대표 업무는 로봇 교실에 배정하고, 회로 교실의 부족을 확인하고, 빛 교실에 남은 수량을 배정한 뒤 전달 목록을 다시 열어 읽는 것이다.
- 자체 검증 보고에 실행 방법, 실제 확인한 항목과 결과, 확인하지 못한 항목을 구분한다.
