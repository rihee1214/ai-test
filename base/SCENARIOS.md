# 조작별 예상 결과

‘대’는 대기, ‘완’은 배정 완료다. 세 글자는 K01·K02·K03 순서다. 전달 목록 칸의 번호는 해당 수업명과 수량이 화면에 보인다는 뜻이다. S0부터 S8까지 연속이며 S9만 독립 실행한다.

|단계|시작 데이터|행동|예상 화면|종료 상태 · 잔량 / 세 행 / 전달 목록|
|---|---|---|---|---|
|S0|빈 프로필, 원본|처음 열기|초기 목업, 세 행 모두 배정|4 / 대대대 / 비어 있음|
|S1|S0의 결과|K01 배정|잔량 1, K01 배정 완료·취소|1 / 완대대 / K01 3개|
|S2|S1의 결과|K02 배정|재고 부족, 1개 부족. K02는 계속 대기|1 / 완대대 / K01 3개|
|S3|S2의 결과|K03 배정|조작 후 목업, 부족 안내 해제|0 / 완대완 / K01 3개, K03 1개|
|S4|S3의 결과|새로고침 후 탭을 닫고 같은 주소 다시 열기|두 번 모두 S3의 배정 결과|0 / 완대완 / K01 3개, K03 1개|
|S5|S4의 결과|K01 취소|K01 대기, 전달 목록에는 빛 교실만 남음|3 / 대대완 / K03 1개|
|S6|S5의 결과|K01 다시 배정|로봇 교실이 다시 전달 목록의 첫 번째|0 / 완대완 / K01 3개, K03 1개|
|S7|S6의 결과|K02 배정|재고 부족, 2개 부족|0 / 완대완 / K01 3개, K03 1개|

|S9|독립, 원본 복원|K02 배정|회로 교실만 완료·취소|2 / 대완대 / K02 2개|
